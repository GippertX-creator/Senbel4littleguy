先读这一页：你不需要会编程

这是给生理学、病理学、细胞生物学和生物化学学生准备的学习工作台。你可以把它理解为：电脑上一个能整理课件、辅助准备报告、陪你练习的小工具。日常使用不需要输入程序代码。

本说明书对应当前仓库版本，编写日期为 2026 年 10 月 23 日。配图和视频来自真实网页操作；为避免使用真实密钥和产生模型费用，视频中的 AI 返回是固定模拟示例，不代表真实服务商的效果。Windows 安装步骤是文字指导，尚未在真实 Windows 电脑完成实机验证。
你会拿到什么怎样打开
操作演示 MP4双击 docs/media/小家伙的小家伙-操作演示.mp4，用电脑视频播放器观看。视频有中文提示、鼠标高亮和章节，没有配音。

如果你只想先试一次：按第 1～4 节装好并连接 API → 上传一份课件 → 生成知识清单 → 问一个问题。不要一开始把整学期所有材料都上传。

1. 使用前准备好这四样东西

准备项具体要求
一台电脑推荐 Windows 10 / 11，64 位（x64），安装 Edge 或 Chrome。可在“设置 → 系统 → 系统信息/关于 → 系统类型”查看。Mac、手机不适用下面的 Windows 双击安装流程。
项目压缩包从项目 GitHub 仓库下载 ZIP，或使用维护者提供的“小家伙的小家伙-Windows.zip”。不需要在 GitHub 网页上逐个复制代码。
模型服务三项信息API 基础地址、模型名称、API 密钥。这些信息由你的模型服务商提供。前三个词不懂没关系，第 4 节有解释。
一份课程材料例如一章 PPTX、可选择文字的 PDF 或 DOCX；没有正式课件也可以先用随包的练习材料。

第一次启动需要联网下载组件。以后打开界面、管理材料和指图练习主要在本机完成；使用远程模型生成内容时仍需要联网。AI 功能可能按服务商规则计费，工作台本身不会替你充值。

ChatGPT 等聊天网站的会员，并不自动等于能在本软件使用的 API 余额或密钥。不要把网站登录密码填进 API 密钥框。

2. 下载、解压，再安装 Python

  1. 打开项目仓库：https://github.com/GippertX-creator/Senbel4littleguy 。确认页面分支选择的是 main。
  2. 点击绿色的 Code 按钮，再点击 Download ZIP。若拿到维护者给的部署包，可以跳过这一步。
  3. 在电脑“下载”文件夹找到 ZIP，右键选择“全部解压缩/解压到”，选择你容易找到的位置，例如 D:\MedStudy 或“文档”下的学习工具文件夹。不要只在压缩包窗口里双击启动。
  4. 打开解压后的文件夹。可能需要再打开一层 LittleBuddy 或 Senbel4littleguy-main。找到 start.bat、README.md、app 文件夹在同一层的位置。
  5. 访问 Python 官方 Windows 下载页：https://www.python.org/downloads/windows/ 。选择 Python 3.12 的 64 位 Windows 安装程序（Windows installer 64-bit）。需要帮助时，把“请安装 Python 3.12 64 位，并添加到 PATH”这句话给维护者。
  6. 运行 Python 安装程序。在传统安装界面勾选 Add python.exe to PATH，再点击 Install Now。出现安装成功提示后关闭安装程序。
  7. 如果电脑已装 Python 3.11 或以上，可以先尝试下一节。若提示版本太旧，再安装推荐版本。

Python 是让这个学习工具能够运行的基础组件，不是你需要学习的编程课程。只需安装一次，之后每天使用不必重新安装。

Windows 可能默认隐藏“.bat”等文件后缀。这时文件可能只显示为 start；可在资源管理器“查看 → 显示 → 文件扩展名”打开后缀显示，确认类型是 Windows 批处理文件。不要双击 app 文件夹中的程序文件。

3. 第一次打开：只需双击 start.bat

  1. 进入刚才解压后的项目文件夹，双击 start.bat。
  2. 出现一个黑色或深色窗口是正常现象。首次会下载并安装组件，窗口可能不断滚动英文内容；请等待，不要连续双击启动多个窗口。下载速度取决于网络。
  3. 完成后浏览器会自动打开工作台。如果没有自动打开，保持启动窗口运行，在浏览器按 Ctrl+L，在顶部地址栏输入 http://127.0.0.1:8765 ，再按回车。不要把它输入到网页内的搜索框。
  4. 看到“小家伙的小家伙”标题、左侧功能菜单和小猫，说明网页已打开。接下来配置 API，不要关闭启动窗口。

127.0.0.1 的意思是“这台电脑自己”。这是访问本机工具的地址，不是需要注册的网站，也不能发给同学让他们在另一台电脑直接访问。

你看见的现象代表什么
黑色启动窗口一直开着正常。它负责让网页背后的工具运行。最小化即可。
浏览器页面出现但显示 API 设置正常。界面已运行，还没有输入本次使用的模型连接。
页面打不开或无法访问先确认启动窗口没有关闭，地址是 http://127.0.0.1:8765。
Python was not found / Please install Python没有找到合适的 Python，回到第 2 节安装并勾选 PATH。

以后的每日启动仍是双击同一个 start.bat。成功安装过的组件会复用，通常不需要重新下载全部依赖。

3a. 小猫伙伴：互动、散步与 CG 收藏

  1. 点击右下角小猫，展开互动面板。可以摸摸、喂点心、逗毛球、听它撒娇；这些互动不需要配置 API。
  2. 选择“让它散步”，再点击面板右上角 × 收起对话。小猫会沿页面底部爬行；摸摸它、输入文字、处理学习任务或暂停动画时会停下。
  3. 点击小猫下方的“♥ CG”，或左侧“小猫互动与 CG”，打开收藏。选择已解锁的图片，用“下一句”阅读小剧情，最后选择自己的回应。按 Esc 或点右上角 × 关闭。
  4. 需要专心时选择“收起小猫”；右下角会保留“叫回小猫”按钮。“暂停动画”及系统减少动态效果设置同样适用。

4. API 设置：三个框分别填什么

API 可以理解为“软件向模型提问的连接方式”。你需要向自己选用的模型服务商获取下面三项信息；不是从演示视频中照抄。

页面中的名称通俗解释你应填写什么
API 基础地址通往模型服务的入口服务商提供的 OpenAI 兼容基础地址。例如 https://api.openai.com/v1 只是一个格式例子，需确保你有该服务的访问权限和账户。不要加 /chat/completions。
模型名称要使用哪一个模型逐字复制服务商给出的模型标识，包括大小写和符号。不要填“随便”“ChatGPT”等不确定名称。
API 密钥允许软件使用你账户额度的凭据从服务商控制台复制的 API Key。不是网站密码，也不是复制视频中的 DEMO 字符串。
  1. 点击左侧“API 设置”。
  2. 按服务商说明填写基础地址和模型名，再粘贴密钥。远程地址使用 https://。
  3. 点击“保存并测试连接”。这个按钮一次完成保存和测试；只想保存而不发送请求时，选择“仅保存设置”。密钥旁的“显示/隐藏”可帮助检查粘贴内容，检查后请隐藏。
  4. 看到“API 请求成功；可以开始学习”再继续。若提示“API 连接成功，模型已响应；短测试达到输出上限”，表示连接可用，但尚未验证完整生成，可先用少量材料试生成。若出现错误，按第 15 节排查。
密钥仅保存在当前启动窗口对应的运行进程中。关闭服务或关机后，需要重新填写密钥；基础地址和模型名通常会保留。只刷新网页、且服务仍在运行时，一般不必重新输入。不要把真实密钥发给同学、贴在群里或出现在截图中。

右上角“API 已配置”表示本次运行已有密钥，不等于所有模型请求都一定成功。测试连接只验证一次基本请求，后续生成还可能受额度、网络、模型输出格式或材料长度影响。模型应支持 OpenAI 兼容 Chat Completions 与中文 JSON 输出。

展开“生成设置（出现截断时查看）”，可以调整首次输出额度，默认 8192 token。DeepSeek 官方接口默认选“快速生成”，请求关闭深度思考；可自行改为深度思考或沿用模型默认模式。其他服务不受这个选项影响。如果模型不接受思考参数，请选“沿用模型默认模式”。部分模型的思考过程也占用输出额度。

输出被截断或引用位置不合法时，工作台合计最多自动重试一次，可能增加费用。截断重试会提高额度，最高翻倍且不超过 65536 token。请确认重试额度也在模型支持范围内；例如模型最多允许 8192，就将首次额度设置为 4096 或更低。连续截断或引用仍不合法的结果不会保存。每次请求可能需要较长时间，请等待当前操作完成再重试。

没有 API 时，仍可上传和查看材料、建立图片标注、进行指图练习，并复习已有记录；生成新知识清单、AI 答疑、小测和报告则需要可用模型。

5. 上传材料：先选课程，再选用途

  1. 在右上角“当前课程”选择生理学、病理学、细胞生物学或生物化学。不同课程的材料和记录分开管理。
  2. 点击左侧“课程材料”。
  3. 在“材料用途”选择课程材料、实验材料或报告模板。
  4. 点击文件选择框，找到电脑里的文件；可以按住 Ctrl 选择多份同用途文件。
  5. 点击“上传并解析”，等待下方列表出现文件名称。文件进入列表，才表示上传完成。
  6. 点击文件右侧“查看原文”，检查文字是否提取完整。
用途适合上传什么后续用在哪里
课程材料教师 PPT、课程讲义、课后阅读知识清单、课程助教、讲解反馈、小测。
实验材料实验指导书、老师给的实验原理与操作内容报告固定内容、实验原理学习、小测。
报告模板学校要求的 Word 实验报告格式报告结构和版式；模板本身不作为医学事实来源。

上传成功后，可以直接点击“生成知识清单”或“准备实验报告”等下一步按钮。填写过的主题、报告标题等会在本次打开页面期间保留；刷新或关闭页面后需要重新填写。API 密钥不会作为表单草稿保存。

文件类型注意事项
PPTX支持幻灯片文字、表格和备注。旧版 PPT 请先在 PowerPoint 或 WPS 中“另存为 .pptx”。
PDF可选择、复制文字的 PDF 更合适。扫描照片式 PDF 需先做 OCR（把图片文字识别成可复制的文字）。
DOCX支持 Word 段落和表格。旧版 DOC 请另存为 DOCX。
TXT / MD支持纯文字材料。不会保留原文件复杂版式。
文件大小单个课程/实验/模板文件最大 25 MB；过大时按章节拆分。图片在“指图学习”上传。

PPT 或 PDF 中的图像、曲线和图片里的文字不会自动全部理解。仅有“上传成功”不代表每张图都读懂了。图像题可以使用指图学习，或补充图片的文字说明。

5a. 只整理指定章节，也可以下载 PDF

  1. 进入知识清单、课程助教或学习智能体等页面，在“学习依据”中勾选目标文件。
  2. 展开“限定章节或位置”，把“范围方式”改为“只整理指定章节”，选择目标文件和目录章节。
  3. 核对章节名称与起止位置。没有可靠目录时，改用“手动选择页码位置”，分别选择开始和结束位置。
  4. 填写主题或具体要求后生成。网页结果上方会标明实际采用的范围。
  5. 点击结果旁的“下载 PDF”，保存到电脑。浏览器通常放到“下载”文件夹，可按 Ctrl+J 查看。

目录依据 PDF 书签、Word 标题样式、PPT 章节标题或文字中的明确章节标题识别。请先核对原文；缺少目录时不会由模型猜测章节边界。PDF 的“第 N 页”是文件物理页序号，可能与正文印刷页码不同；Word 使用段落、表格位置。扫描 PDF 仍需先做 OCR。

限定后只会发送目标文件在所选范围内的文字，不会混入其他已勾选文件。主题用于在范围内聚焦，不能代替章节选择。范围在本次打开页面期间沿用，切换课程会清除；要恢复所有所选材料，切回“所选材料的相关片段”。

很长的章节仍可能只使用其中的相关片段，页面和 PDF 都会提示未覆盖全部。可以再缩小范围、按小节分批整理。章节检测和生成结果仍需对照课程原文核对。

清单、答疑、小测、概念对照、讲解反馈和报告均可下载 PDF；报告同时保留原有 Word 下载。下载依据已保存结果生成，不再次调用模型。小测 PDF 是练习版，不包含隐藏答案或解析；完成网页作答后在网页查看解析。PDF 是便于阅读的排版，不保留网页动画或学校 Word 模板的复杂格式。

6. 知识清单：从一章课开始

  1. 点击左侧“知识清单”。
  2. 学习材料默认已选中；需要调整时展开“学习依据”，可以全选、清空或逐个勾选。实验报告页还可一键只选实验材料。报告模板不能单独提供知识来源。
  3. 要只整理某章，先按第 5a 节选择章节。在“本次学习主题”写一个小主题，例如“心肌兴奋性”“细胞损伤”“酶活性与控制变量”；也可以留空。
  4. 点击“生成知识清单”，等待生成完成。处理时不要连续点击或切换课程。
  5. 阅读知识点、机制联系和主动回忆问题。点击“加入主动回忆”，把这些问题放入今日复习；需要离线阅读时点击“下载 PDF”。

如果出现“只使用部分片段”的提示，说明材料太长，本次只选择了相关部分。缩小主题或减少勾选材料，再分批整理；不要把一次清单当作整学期内容的完整覆盖。

6a. 学习智能体：直接说出要求，再继续追问

  1. 点击左侧“学习智能体”，或首页“把学习任务交给小家伙”的入口。
  2. 勾选材料；希望严格限定章节时，可先在范围面板选好。
  3. 输入要求，例如“只用这份讲义第二章，整理 5 个核心知识点，再出 2 道题，保留网页结果并提供 PDF”。
  4. 如果小家伙询问文件、章节或任务类型，直接在同一个输入框补充。像“帮我复习”这样的宽泛要求，会先询问你想做清单、答疑还是小测。
  5. 完成后，点击会话中的结果卡查看相应清单或小测；每张卡都可下载 PDF。小测仍需在网页作答后查看解析。
  6. 继续说“再出 1 道题”可以沿用刚才的章节。要取消章节限制，请明确说“改为整份材料”，或新建会话并重新选择范围。

  3. 对照原文确认术语、定义和条件是否一致；PDF 是提取页码，PPT 是幻灯片序号，Word 通常是段落或表格编号。
  4. 点击弹窗右上角 ×，返回学习页面。

8. 课程助教：像问同学一样提问

  1. 点击“课程助教”，确认学习依据已经选择。
  2. 输入一个明确问题，例如“为什么研究温度对酶活性的影响时，需要保持 pH 一致？”
  3. 点击“向助教提问”。小猫会显示思考状态。
  4. 看完解释后点来源核对，再继续追问“如果改为研究 pH 呢？”或“先给我一个提示，不要直接给答案”。

好用的提问方式：①“请用原因—过程—结果解释……”；②“我认为……，其中哪一步有问题？”；③“请只根据所选材料说明，不足时指出缺少什么。”问题越具体，越容易核对。

页面下方“需要帮助？查看使用提示”中提供英文开放教材入口，属于补充阅读，不等于教师指定教材。若术语或教学范围不同，以本课程要求为准。

9. 讲给助教听：检查自己是否真的懂了

  1. 点击“讲给助教听”，填写主题。
  2. 先不抄课件，用自己的话写一段解释。可以按“为什么发生—中间过程—最后结果”组织。
  3. 点击“请助教检查理解”。
  4. 看“已经讲清楚”“需要修正”和“还可以补上的环节”，逐条点来源核对。
  5. 保留正确部分，修改错误说法，再次提交。首版使用文字输入，没有语音录音功能。

这不是正式考试评分，不要把一次反馈当成掌握证明。更好的办法是：修改后合上材料，再解释一遍，过几天再回忆。

10. 实验报告：按学校格式写好，图片和数据逐项填

  1. 在“课程材料”先上传正式实验指导书，用途选“实验材料”；学校格式文件另选“报告模板”上传，使用 DOCX。
  2. 点击“实验报告”，在“学习依据”只勾选与本次实验有关的材料。不要将示例报告当作本次真实观察记录。
  3. 填写实验名称、选择学校模板；没有模板时使用“目的和要求／内容和原理／主要仪器设备／结果与分析／讨论、心得”的五栏结构。
  4. 可展开“填写封面信息”，填入课程名称、姓名、学号等；未提供的信息留空，不沿用模板的旧学生信息。还可填写补充格式与内容要求。
  5. 点击“生成报告与实验学习卡”。核对网页中的每个章节、每张图片框和原始数据记录表。
  6. 点击“下载 Word”，在 Word/WPS 中向相应图框插入本人本次照片，填写每个【填写：……】标记，并核对实际操作条件。
  7. PDF 是便于阅读的内容版；需要与学校 Word 一样的分页和版式时，在 Word/WPS 中打开报告后“另存为 PDF”。

理论分析和讨论会先写好，依赖实际观察的地方保留具体填空，不生成“本次已成功观察到……”之类未经提供的结果，也不代编个人经历。原文没有的事实须补充材料。正式提交前核对教师要求及学校允许的 AI 使用范围。旧报告记录保持原样，需要重新生成才能获得新版内容。

11. 学校模板对不上，怎么办？

模板决定格式，实验材料决定内容。最可靠的方式是在学校 DOCX 模板对应位置放入占位符。占位符就是一对双大括号包住的字段名。

  1. 在实验报告页点击“下载占位符模板”，先看看示例；也可使用 docs/examples/03-演示报告模板.docx。
  2. 用 Word/WPS 打开学校模板，在需要放实验目的正文的位置输入 {{实验目的}}，在原理位置输入 {{实验原理}}，依次放好其他占位符。
  3. 保留学校要求的标题、表格和字号，把模板另存为一个新的 DOCX。
  4. 回到“课程材料”按“报告模板”上传这个新文件；在实验报告页重新选择并生成。

支持的中文占位符：{{实验名称}}、{{实验目的}}、{{实验原理}}、{{仪器与试剂}}、{{实验步骤}}、{{注意事项}}、{{实验数据}}、{{实验结果}}、{{分析与讨论}}、{{实验结论}}。不要省略大括号，也不要换成全角括号。

普通 DOCX 可直接识别“实验目的和要求（必填）”“实验内容和原理”“主要仪器设备”“实验结果与分析”“讨论、心得”等标题，也支持示例中的七栏结构和表格内的章节栏。按章节填入时会替换旧正文、旧表格与示例照片，保留封面图、章节顺序、页面设置。占位符模板保留原文字版式，复杂图表位置以文字标记呈现。

不能识别章节的模板或非 DOCX 模板会在生成前提示，不再静默切换成其他格式。可以另存为 DOCX、加入支持的标题或使用下载的标准模板。模板只约束格式，不把模板里的旧结果和旧个人信息发送给生成模型。请最终检查换页、表格空间与学校格式；原模板文件不会被覆盖。

在“学习智能体”中生成报告时，也可在输入框上方选择“生成实验报告时使用的模板”；未选时使用五栏标准结构。

12. 小测与易混练习：先做，再看答案

  1. 点击“小测与易混练习”。在“章节小测”选择材料、填写主题、选择题量，然后生成。
  2. 为每一道题选一个答案，答完后再提交。提交前不显示标准答案与解析。
  3. 提交后查看正确题数、解析和来源。错题会加入今日复习，不需要另外复制。
  4. 想区分两个概念时，切换到“易混知识对照”，填写概念 A、概念 B，并先写下自己的初步判断。
  5. 生成后对照比较表，再完成下面的新情境题。初步判断主要供你自我对照；需要逐句纠错时，使用“讲给助教听”。

自动生成题目可能存在歧义或材料支持不足。发现疑问时先点来源，并请教师或助教核对，不要仅凭工具答案改掉正确的教材知识。

13. 指图学习：自己建立可靠的小题库

  1. 准备一张没有现成答案标签的图片，推荐教师提供的图谱或课程示意图。PNG、JPG 或 WebP，最大 10 MB。
  2. 点击“指图学习”，上传图片。
  3. 在图片上点击你要练习的结构，出现数字标记。
  4. 在右侧填写结构名和辨认依据/出处。接受多个名称时用 / 分隔，例如“细胞核 / nucleus”。
  5. 对照教师图谱确认名称和位置正确，再勾选确认并点击“保存标注”。修改名称后，需要重新确认。
  6. 切换到“隐藏标签练习”，按编号输入结构名，提交后核对。没有匹配到的正确别名，可以自己核对后回到标注中补充。
这里不自动诊断病理切片，也不自动判断未知图片的结构。题目质量取决于已确认标注。系统不会擦掉原图中印着的答案；如果原图有答案，应先换一张适合练习的图。

14. 今日复习、小猫互动和历史记录

  1. 点击“今日复习”，先尝试写下你记得的内容，再点击“查看参考内容”。
  2. 对照后选择“已能回忆，安排下次”或“还需巩固，明天再练”。这是自评，不是机器给你的医学能力评分。
  3. 能回忆后的间隔依次为 1、3、7、14、30、60 天；未记住时明天再练。当前课程没有到期卡片时会提示今日完成。
  4. 各学习页上方的“已保存的学习记录”可以展开，查看原有清单、报告、小测或反馈。切换课程后，记录也随课程切换。

点击首页或右下角小猫，可以摸摸它或打开提示。提示框内可暂停/开启动画，也可点击 × 收起。摸猫和这些动画不消耗模型额度。等待时的思考、完成后的庆祝，都只是请求状态。

字体看不清时，点击右上角“大字”切换为大字模式，再点“标准字”恢复。选择会保存在当前浏览器。常见操作完成后，小猫只改变状态，不会反复弹出提示遮挡内容；需要时点击它即可。

给自己一个可执行的节奏：课后整理一小章 → 解释一个机制 → 做 5 道题 → 第二天花 10 分钟回忆。每次范围小一点，比一次生成大量内容更容易真正用起来。

16. 关闭、备份、换电脑和更新

  1. 结束使用时先保存正在编辑的 Word 文件。回到启动窗口，按 Ctrl+C；若 Windows 询问是否终止批处理，可按提示确认。
  2. 关闭服务后，在项目文件夹找到 data 文件夹。把整个 data 复制到自己的备份位置，例如移动硬盘。不要在服务正在写入时直接替换数据库文件。
  3. 换电脑时：重新下载/解压项目并安装 Python，先不要启动；把自己的备份 data 文件夹放进新项目、与 start.bat 同一层，再启动。
  4. 更新代码时：先关闭服务并备份 data，把新版解压到新文件夹，将旧 data 复制过去。新版本可能重新安装所需组件；不要直接删除旧资料。
  5. 更新或换电脑后，重新填写 API 密钥并测试。建议确认材料和报告都在，再处理旧项目文件夹。

data 保存材料、图片、记录和导出报告；.venv 是运行组件，通常不需要迁移；dist 是维护者生成的部署包。初学者只需记住：备份 data，启动 start.bat。关闭浏览器标签页不会自动关闭服务，关掉启动窗口才会结束本次运行。
