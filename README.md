# 小家伙的小家伙 · 基础医学学习工作台

面向**生理学、病理学、细胞生物学、生物化学**的个人学习工具。Python 本地服务 + 浏览器界面，无需 Node.js、数据库服务器或 Docker。手动连接 OpenAI 兼容 API；数据保存在本机。

## 更清楚、更省步骤的界面

正文与输入框采用至少 16px 字号、加深的文字颜色和更宽松的行距。右上角“大字”可将主要文字切换为 18px，字号选择保存在当前浏览器。首页按“选课程 → 上传材料 → 开始学习”提供引导和四个常用入口。

上传支持拖拽和文件选择，完成后可直接进入知识清单或实验报告。材料可一键全选、清空；报告页还可只选实验材料。API 页以“保存并测试连接”为主要操作，并提供显示/隐藏密钥按钮。材料或模型尚未准备好时，会先提示下一步。

## 按章节整理、下载 PDF 与统一学习智能体

在“学习依据”下展开 **限定章节或位置**，选择目标文件和章节；没有可靠目录时，手动选择起止页码、幻灯片或段落。生成前先裁切所选范围，只向模型提供该文件在范围内的文字。PDF 使用物理页序号，目录检测结果请对照原文；很长的章节仍可能只使用相关片段，网页会提示覆盖情况。

清单、答疑、小测、概念对照、讲解反馈和报告均保留网页结果，并提供 **下载 PDF**；报告同时保留 Word 下载。PDF 从已保存结果排版，不再次调用模型，也不需要额外安装浏览器或中文字体。小测 PDF 是练习版，答案与解析仍需完成网页作答后查看。

点击左侧 **学习智能体** 或首页入口，可以直接说：“只用第二章，整理 5 个知识点，再出 2 道题，提供 PDF。”要求模糊时先澄清文件、范围或任务类型，一次最多执行 3 个已有学习任务；继续说“再出 1 道题”会沿用刚才的范围。明确说“改为整份材料”可以解除章节限制。每次小测支持 1–10 题，会话按课程保存在本机，刷新后可选择继续。

规划和每项生成可能分别调用 API，下载已有 PDF 不调用模型。智能体只调用现有学习功能，不联网搜索或执行程序；真实模型仍可能理解错误，请核对所选范围和医学内容。详见[说明书第 5a、6a 节](docs/使用说明书.md)。原有操作视频早于这些新功能，可参考新增图文步骤。

## 实验报告：学校格式、逐项图位与原始记录

实验报告按所选 DOCX 模板的章节组织；默认采用“目的和要求／内容和原理／主要仪器设备／结果与分析／讨论、心得”五栏格式，也支持七栏学校格式。保留封面与页面设置，按章节替换旧正文、示例表格和照片；封面信息可在网页填写，未提供的姓名、学号等留空，不沿用模板旧内容。未知格式或非 DOCX 模板会在生成前提示。

除了固定内容，还会写好有材料依据的理论分析、讨论与结论句式；每个观察对象/实验分组对应明确的数据填写栏，每张本人照片对应图框、图片要求、图注及倍率/通道等填写位置。依赖本次结果的句子使用 `【填写：具体内容】`，不把理论预期写成已完成的真实观察。网页、Word 与 PDF 阅读版使用同一份结构；学校精确版式以 Word 为准，可在 Word/WPS 另存 PDF。原有历史报告需重新生成才能使用新版结构。

详见[说明书第 10、11 节](docs/使用说明书.md)。模板只用于结构，医学内容仍以所选实验材料为依据；不会提交模板旧姓名和样例正文给生成模型。原始上传文件不随代码推送。

## 会散步的小猫与 CG 收藏

点击右下角小猫，可以摸摸、喂点心、逗毛球或听它撒娇。选择“让它散步”，收起对话后会沿页面底部爬行；输入文字、处理任务或暂停动画时会停下。支持收起小猫、随时叫回，并遵循系统“减少动态效果”设置。

点击小猫下方的 **♥ CG** 或左侧 **小猫互动与 CG**，进入三张原创 CG 和带选择的小剧情：阳光书桌初见、雨天毛球、星夜晚安。第一张直接开放，第二张好感达到 10 解锁，第三张好感达到 24 或成功完成 3 次学习操作解锁。互动和成功学习会增加好感，离开不会扣分。

互动、CG 与固定文字剧情无需 API，也不消耗模型额度；无配音。进度保存在当前浏览器的本机网站数据中，更换浏览器/访问端口或清除网站数据不会自动同步，不包含在 `data` 文件夹备份中。新互动可观看[专门演示](docs/小猫互动演示.html)，或查看说明书第 3a 节；CG 收藏窗口也提供演示入口。

主题、报告标题、讲解等表单内容在本次页面打开期间保留，切换功能或课程后可以继续填写；刷新/关闭页面后草稿不保留。API 密钥不进入这些草稿。补充说明默认收起，常规任务完成后小猫只改变状态，需要时再点击查看提示。

## 小猫学习伙伴

工作台以奶油色、淡紫色和蜜桃色呈现，小猫抱着课本陪你学习：首页、助教头像和右下角使用同一个猫咪形象。待机时轻轻呼吸，处理请求时摇头思考并显示提示，完成时跳跃庆祝，遇到错误时提醒检查；点击小猫可以摸摸它，打开学习提示或进入课程助教。

摸猫与状态动画不会调用 API。提示框可收起，也可通过“暂停动画”关闭猫咪动态（选择保存在当前浏览器）；系统开启“减少动态效果”时自动减少动画。猫咪状态对应软件请求进度，不代表生成内容已经核实。

## Windows 启动

1. 在 Windows 10 / 11（x64）安装 [Python 3.12](https://www.python.org/downloads/windows/) 64 位版（最低 3.11），安装时勾选 **Add python.exe to PATH**。
2. 下载项目并解压到可写的目录，例如 `D:\MedStudy`。不要仅在 ZIP 中打开，也不要放在 `Program Files`。
3. 双击 **start.bat**。首次会创建 `.venv` 并联网安装固定版本的依赖；后续启动复用依赖。窗口保持打开。
4. 浏览器自动打开工作台；未打开时，访问 `http://127.0.0.1:8765`。
5. 打开 **API 设置**，填写基础地址、模型名、API 密钥，点击“测试连接”。不用在聊天中提供密钥。

远程服务使用 HTTPS。基础地址示例为 `https://api.openai.com/v1`，不要填写 `/chat/completions`。模型必须支持中文与 JSON 输出。API 不兼容 Responses-only 服务；部分仅接受特殊参数的推理模型需使用服务商提供的兼容模型。本机模型可使用 `http://127.0.0.1:11434/v1`（需自行安装模型并启动兼容服务），无鉴权时可不填密钥。

**密钥仅保存在服务进程内存中**，不写入数据库、文件或浏览器存储；服务关闭后重新填写。基础地址和模型名称保存在本机。测试连接会发起一次短请求，可能产生少量费用。

如果测试提示“API 连接成功，模型已响应；短测试达到输出上限”，连接已经建立，但尚未验证完整内容生成。推理模型可能在短测试中用完输出额度，可先用少量材料试生成；测试不会上传课程材料。实际学习内容被截断时仍会报错，不保存未完成结果。

**知识清单或助教答疑被截断时**：最新版默认首次输出额度为 8192 token，DeepSeek 官方接口默认请求关闭深度思考，并使用 JSON 输出模式。可在 **API 设置 → 生成设置** 调整额度和 DeepSeek 生成方式；旧设置会自动补齐默认值。首次截断时会提高额度重新生成一次（最高翻倍、不超过 65536 token），可能增加费用，请确认重试额度也符合服务商限制。连续截断仍会报错，未完成内容不会保存。若旧模型不接受 DeepSeek 思考参数，选择“沿用模型默认模式”；其他服务不会收到 DeepSeek 专用参数。深度思考开关的实际支持情况以所选模型为准。

**提示引用了未提供的位置时**：最新版使用短来源标识，由程序还原为实际文件和页码，减少模型抄错材料编号或页码格式的情况。来源不合法时自动重新生成一次，仍不合法则不保存。引用修复与截断合计最多自动重试一次，可能增加费用；只接受本次实际发送的材料片段，不会把未选材料或未发送的页码替换成“可用引用”。无需重新上传已有材料，更新并重启即可使用新协议。

关闭服务：在启动窗口按 `Ctrl+C`。端口冲突时，从项目目录运行：

```powershell
py -3 launch.py --port 8766
```

## 一次完整的学习流程

1. 切换课程，在“课程材料”上传 PPTX、PDF、DOCX、TXT 或 MD，区分课程材料、实验材料和报告模板。旧版 `.ppt` / `.doc` 请另存为新格式。单文件最大 25 MB。
2. 在“知识清单”选择材料与主题，生成知识点、机制因果链和主动回忆问题；来源标签可查看提取原文。点击“加入主动回忆”形成复习卡。
3. 在“课程助教”连续提问；在“讲给助教听”用自己的话解释知识点，检查已掌握、错误和遗漏，修正后再次提交。首版采用文字输入。
4. 在“实验报告”填写实验名，选择模板，生成固定内容并下载 Word。附带实验原理与对照设计小测，连接实验和学习。
5. 在“小测与易混练习”生成章节题；易混练习先写下初步判断，再查看对照表、完成新情境题。提交后显示解析，错题进入复习。
6. 在“指图学习”上传无答案标签的图片，点击结构添加标注，填写名称、辨认依据和教材出处，确认后保存。练习隐藏用户建立的标签，按编号填写结构名。名称可用 `/` 分隔可接受的同义词；不匹配的别名需自行核对后补充。
7. 在“今日复习”先写回忆，再看参考内容，自评掌握情况。记住后的间隔依次为 1、3、7、14、30、60 天；未记住则明天再练。这里只提供自评记录，不以关键词匹配评价开放式理解。

材料推荐以当前材料中的可点击原文出处为基础；助教页另外提供按学科整理的英文开放教材入口。不会生成未经核验的参考链接或推测教师考试重点。

## 实验报告模板

完整生成固定内容、有依据的理论分析讨论、图注及结论句式；每份报告至少包含原始记录表和图片位置。实际观察与测量值、本人图片，以及依赖真实结果的判断留明确填空；材料未提供的步骤、试剂浓度等注明需要补充。

工作台可下载示例 DOCX 模板。推荐在学校 Word 模板中放置以下占位符，支持段落和表格，字体样式以占位符所在位置为准：

```text
{{实验名称}}  {{实验目的}}  {{实验原理}}  {{仪器与试剂}}
{{实验步骤}}  {{注意事项}}  {{实验数据}}  {{实验结果}}
{{分析与讨论}}  {{实验结论}}
```

也支持英文键 `{{title}}`、`{{purpose}}`、`{{principle}}`、`{{equipment}}`、`{{steps}}`、`{{precautions}}`、`{{data}}`、`{{results}}`、`{{discussion}}`、`{{conclusion}}`。

没有占位符的 DOCX 按支持的章节标题填写，并保留封面、页面设置与外层表单结构；章节内的旧正文、表格与示例照片替换成新报告。占位符形式保留文字版式，图片和数据位置以文字标记呈现。无法识别的模板、非 DOCX 模板在调用生成前提示，不会退回其他结构。原模板不被修改，导出后仍需核对分页、图框与教师要求。

## 能力范围

- PDF 提取文字，PPTX 提取文字、表格与备注，DOCX 提取段落与表格；扫描页、图片中的文字以及复杂图示不做自动 OCR。需要先 OCR，或补充对应文字。
- 长材料采用本地关键词检索与片段选择，不额外调用向量模型。超出上下文范围会提示使用片段数量，建议按章节分批处理。
- AI 输出检查 JSON 结构与引用位置是否存在，**不能自动证明引用支持全部医学结论**。学习内容与题目仍需核对教师材料，尤其是图像标注。
- 指图使用人工确认的标准标注，不自动诊断病理切片、不自动识别未知图片。仅隐藏工作台标签，不能擦除原图已有的名称。
- 当前是个人本机版，没有多用户登录、云同步、语音输入或在线服务部署。只监听 `127.0.0.1`，不要改成对外监听用于多人共享。
- 调用 AI 时，所选材料的相关文字和用户输入发送到用户配置的服务；费用、保存与数据处理规则由该服务决定。图片练习和复习调度无需 API。

## 数据与备份

默认 `data/` 内含 SQLite 数据库、上传原件、图片和报告导出。关闭服务后，备份整个 `data/` 文件夹即可。恢复时将其放回同一位置。`data/`、`.venv/` 和 `.env` 已在 Git 忽略列表中。删除材料会删除原件，已有学习记录保留，但原文来源可能无法查看。

高级配置：环境变量 `MEDSTUDY_DATA` 可指定其他数据目录，不含任何 API 密钥。

## 开发与验证

```bash
python launch.py --install-only
# Windows: .venv\Scripts\python.exe；macOS/Linux: .venv/bin/python
.venv/bin/python -m unittest discover -s tests -v
.venv/bin/python launch.py --no-browser
```

Windows PowerShell 中对应命令为：

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
.\.venv\Scripts\python.exe launch.py --no-browser
```

可选浏览器集成测试（开发人员）：在测试用 Python 环境安装 `playwright` 与 Chromium 后运行 `python scripts/browser_smoke.py`。也可用 `--browser-path` 指定已有浏览器。测试启动隔离的临时数据目录和本机模型模拟服务，不使用真实密钥；模拟的医学内容仅用于检查软件流程。

重录演示与重建说明书（仅开发人员）：准备 Playwright/Chromium、Playwright 视频编码器、系统 ffmpeg 和 matplotlib，运行 `python scripts/record_demo.py`，随后运行 `python scripts/build_manual.py`。录制在隔离临时数据目录中完成，不读取个人学习数据，不调用真实模型。普通用户只需打开已生成的视频与 PDF，不需要安装这些录制工具。

后端 `app/main.py`，材料解析 `app/extract.py`，API 与检索 `app/ai.py`，报告导出 `app/reporting.py`，浏览器界面 `app/static/`。

自动化测试使用隔离的临时数据库与模拟的 OpenAI 兼容响应，验证材料解析、请求结构、引用拒绝、答案隐藏、评分、复习、报告版式和图片标注流程。**测试不证明某个真实服务商或模型可用**，真实 API 需在用户电脑上输入密钥后测试。当前构建验证运行在 Linux；Windows 启动脚本已提供，但尚未在真实 Windows 机器执行。
