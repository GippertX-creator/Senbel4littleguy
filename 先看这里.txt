欢迎使用「小家伙的小家伙」！

如果你不熟悉电脑，请先不要逐个打开程序文件。

第一步：确认已经把 ZIP 压缩包“全部解压”，不是直接在压缩包中运行。

第二步：打开 docs 文件夹，双击“使用说明书.pdf”。
这里从下载、安装 Python、双击启动，到 API 填写和日常学习一步步介绍。
没有 PDF 阅读器也没关系，可以用 Edge 浏览器打开；也提供 Word 和 HTML 版。

第三步：看一遍操作视频。
文件位置：docs → media → 小家伙的小家伙-操作演示.mp4
视频有中文步骤提示和鼠标高亮，没有配音，可以随时暂停。
注意：片中 API 是模拟示例，地址、模型名、演示密钥不能照抄。

想先看看会散步的小猫：
打开 docs → 小猫互动演示.html，可直接播放并选择章节；
也可以双击 docs → media → 小家伙的小家伙-小猫互动演示.mp4。
这段视频有中文提示、无配音，展示摸摸、点心、毛球、爬行和三张 CG，不调用 API。

第四步：按说明书安装 Python，然后回到本文件所在的文件夹，双击 start.bat。
出现启动窗口后不要关闭；浏览器会打开工作台。
在“API 设置”里填自己的服务商地址、模型名和密钥，再测试连接。

没有正式课件时，可先用 docs → examples 中的练习材料学习操作。
练习材料不代替真实课程、完整实验方案或标准图谱。

以后每天：双击 start.bat → 填本次 API 密钥 → 开始学习。
结束使用：在启动窗口按 Ctrl+C。备份时先关闭服务，再复制整个 data 文件夹。

说明书更新于 2026-10-18，新增小猫互动视频。Windows 安装步骤仍需在你的电脑上验证。
